# 🍿 Palomita — Catálogo de Películas y Series

**Palomita** es una aplicación web interactiva y responsiva para consultar películas y series en tiempo real, desarrollada con JavaScript Vanilla (ES6+) y la API de [TMDB (The Movie Database)](https://www.themoviedb.org/).

El proyecto cuenta con integración completa con **Firebase** para gestión de usuarios (Autenticación) y almacenamiento de favoritos en la nube (Firestore Database).

---

## 🚀 Características Principales

* 🎬 **Catálogo en vivo:** Películas populares, mejor valoradas y próximos estrenos obtenidas directamente de TMDB API.
* 🔍 **Búsqueda y Filtros:** Búsqueda en tiempo real por título y filtrado por géneros cinemáticos.
* 🌐 **Soporte Multilingüe (i18n):** Alternancia dinámica entre Español (ES), Inglés (EN) y Ruso (RU) con persistencia en `localStorage`.
* 📱 **Diseño 100% Responsivo:** Adaptado minuciosamente para móviles, tablets y escritorio (CSS Grid & Flexbox).
* 🔐 **Autenticación con Firebase:** Registro e inicio de sesión de usuarios mediante correo y contraseña.
* ❤️ **Lista de Favoritos:** Guardado de películas favoritas sincronizado en Firestore para usuarios autenticados.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica.
* **CSS3:** Flexbox, CSS Grid, Variables CSS, Media Queries (Mobile First).
* **JavaScript (ES6+):** Async/Await, Fetch API, DOM Manipulation, Modules.
* **TMDB REST API:** Proveedor de datos cinemáticos y pósters.
* **Firebase (v10+):** Authentication & Firestore Database.

# 🍿 Palomita — Movies & TV Shows Catalog (English Version)

**Palomita** is an interactive and responsive web application for exploring real-time movies and TV series, built with Vanilla JavaScript (ES6+) and the [TMDB API (The Movie Database)](https://www.themoviedb.org/).

The project features full **Firebase** integration for user management (Authentication) and cloud-based favorites storage (Firestore Database).

---

## 🚀 Key Features

* 🎬 **Live Catalog:** Popular, top-rated, and upcoming movies fetched directly from TMDB API.
* 🔍 **Search & Filters:** Real-time search by title and filter by genres.
* 🌐 **Multilingual Support (i18n):** Dynamic language switching between Spanish (ES), English (EN), and Russian (RU) with `localStorage` persistence.
* 📱 **100% Responsive Design:** Carefully tailored for mobile, tablet, and desktop viewports (CSS Grid & Flexbox).
* 🔐 **Firebase Authentication:** User registration and login using email and password.
* ❤️ **Favorites List:** Movie bookmarking synchronized in Firestore for logged-in users.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup.
* **CSS3:** Flexbox, CSS Grid, CSS Variables, Media Queries (Mobile First).
* **JavaScript (ES6+):** Async/Await, Fetch API, DOM Manipulation, Modules.
* **TMDB REST API:** Movie metadata and poster images.
* **Firebase (v10+):** Authentication & Firestore Database.
