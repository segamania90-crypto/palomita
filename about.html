Acerca de Palomita

Palomita es un catálogo de películas y series creado como proyecto de portafolio, con el objetivo de practicar JavaScript, trabajo con el DOM y consumo de APIs externas.

Todos los datos de películas, pósteres y sinopsis provienen de la API pública de TMDB (The Movie Database).

Este producto usa la API de TMDB pero no está respaldado ni certificado por TMDB.
